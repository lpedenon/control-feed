# Security

## Reporting a problem

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/lpedenon/no-brainrot/security/advisories/new),
not in a public issue. You will get a reply within a week.

## Supported versions

Fixes go into the latest release. Please update before reporting.

## Scope

No Brainrot runs only on `youtube.com` and `instagram.com`, needs only the
`storage` permission and makes no network requests of its own. Reports about
anything that weakens that, such as a way for a page to read or change your
settings, are especially welcome.
